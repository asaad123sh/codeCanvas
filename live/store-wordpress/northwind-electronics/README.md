# Northwind Electronics — gear that works as hard as you do

WordPress theme generated by **WebCraft Pro** with 13 page template(s).

## Install

1. Zip the `northwind-electronics` folder.
2. WordPress admin - Appearance - Themes - Add New - Upload Theme.
3. Activate, then edit a page and pick its template under **Page Attributes**.

## Page templates

- **Home** - `page-index.php` (template slug `index`)
- **Shop** - `page-shop.php` (template slug `shop`)
- **Product** - `page-product.php` (template slug `product`)
- **Cart** - `page-cart.php` (template slug `cart`)
- **Checkout** - `page-checkout.php` (template slug `checkout`)
- **Order confirmation** - `page-order-confirmation.php` (template slug `order-confirmation`)
- **Track order** - `page-track-order.php` (template slug `track-order`)
- **Wishlist** - `page-wishlist.php` (template slug `wishlist`)
- **Cash on delivery** - `page-cash-on-delivery.php` (template slug `cash-on-delivery`)
- **About** - `page-about.php` (template slug `about`)
- **Contact** - `page-contact.php` (template slug `contact`)
- **Admin** - `page-admin.php` (template slug `admin`)
- **Seller panel** - `page-seller.php` (template slug `seller`)

The nav bar and footer are separate documents in the builder and are already
baked into every template, so no menu assignment is needed.
