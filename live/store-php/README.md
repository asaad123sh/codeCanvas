# Northwind Electronics — gear that works as hard as you do

Multi-page PHP site generated by **WebCraft Pro** (13 page(s)).

## Run locally

```bash
php -S localhost:8000
```

## Custom code

Anything you wrote in the **Code** tab lives in `style.css` (CSS), `script.js`
(JavaScript) and `partials/custom-html.html` (HTML).
